# ☁️ → 👩

Страница-сюрприз: множество фотографий неба слетаются и собираются в её портрет.

**Живая страница:** https://dipav1234.github.io/ana-sky/  ·  (noindex — не индексируется поиском)

## Как это сделано
- `index.html` — движок фотомозаики (vanilla JS + canvas, без сборки).
- `data.js` — фото неба (16 шт.) + крошечная (120px) карта цветов портрета, в base64.
  **Полноразмерного фото в репозитории нет** — мозаика собирается из неба + карты цветов.

## Как поменять текст
В начале `<script>` в `index.html` — блок `CONFIG`:
- `HEADLINE`, `SUBLINE` — подпись, которая проявляется после сборки.
- `TILE_OPACITY` — насколько видны фото-неба поверх портрета.
- `CELL_BUDGET` — детализация (число кусочков).

Сохранить → `git commit` → `git push`. Через минуту страница обновится.

## Локально
Открыть нельзя двойным кликом (нужен http из-за canvas+data). Запусти:
`python3 -m http.server` в этой папке и открой `http://127.0.0.1:8000/`.
